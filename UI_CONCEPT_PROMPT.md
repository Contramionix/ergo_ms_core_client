# Промпт для реализации концептуально нового UI с 4 окнами и переключением модулей

## Концепция интерфейса

Реализовать новый UI для системы ERGO MS, который включает:

### Основные компоненты:

1. **4 независимых окна (как в Windows)**
   - Каждое окно может отображать отдельный модуль или функционал
   - Окна можно откреплять (detach) и прикреплять обратно (dock)
   - Окна можно перемещать, изменять размер, сворачивать и разворачивать
   - Поддержка drag & drop для изменения позиций окон

2. **Нижняя панель с переключением модулей (как в Mac Dock)**
   - Круглые иконки модулей внизу экрана
   - Горизонтальная прокрутка (листание) для навигации между модулями
   - Активный модуль подсвечивается
   - При клике на иконку модуля - он открывается в активном окне или создается новое окно

3. **Система управления окнами**
   - Максимум 4 окна одновременно
   - Возможность закрытия окон
   - Возможность открепления окна (превращение в отдельное окно браузера или overlay)
   - Возможность прикрепления обратно (dock обратно в основной интерфейс)

## Технические требования

### Технологии:
- Vue.js 3 (Composition API)
- Bootstrap 5 для базовых стилей
- CSS/SCSS для кастомных стилей
- Иконки из библиотеки Lucide
- Адаптивный дизайн для мобильных устройств

### Структура компонентов:

```
core/client/src/components/
├── WindowManager/
│   ├── WindowManager.vue          # Главный компонент управления окнами
│   ├── Window.vue                 # Компонент отдельного окна
│   ├── WindowHeader.vue           # Заголовок окна с кнопками управления
│   └── WindowContent.vue          # Контент окна
├── ModuleDock/
│   ├── ModuleDock.vue             # Нижняя панель с модулями
│   ├── ModuleIcon.vue             # Иконка модуля в dock
│   └── ModuleSwitcher.vue         # Компонент переключения модулей
└── WindowControls/
    ├── DetachButton.vue           # Кнопка открепления окна
    ├── DockButton.vue             # Кнопка прикрепления окна
    └── WindowActions.vue          # Кнопки управления окном (свернуть/развернуть/закрыть)
```

### Функциональность:

#### WindowManager:
- Управление состоянием всех окон (максимум 4)
- Распределение окон в сетке (2x2 по умолчанию)
- Обработка drag & drop для изменения позиций
- Управление z-index для активного окна
- Сохранение позиций и размеров окон в localStorage
- Обработка открепления/прикрепления окон

#### Window:
- Отображение контента модуля
- Заголовок с названием модуля и кнопками управления
- Возможность изменения размера (resize handles)
- Перемещение окна (drag)
- Сворачивание/разворачивание
- Закрытие окна
- Открепление (detach) - открытие в новом окне/overlay
- Прикрепление обратно (dock)

#### ModuleDock:
- Горизонтальная прокрутка иконок модулей
- Круглые иконки с анимацией при наведении
- Подсветка активного модуля
- Плавная прокрутка при листании (swipe на мобильных)
- Клик по иконке открывает модуль в активном окне или создает новое
- Отображение уведомлений/бейджей на иконках модулей

### Стилизация:

#### Окна:
- Тени для глубины (box-shadow)
- Скругленные углы
- Плавные анимации при открытии/закрытии
- Градиенты для заголовков окон
- Hover эффекты на кнопках управления

#### Dock:
- Полупрозрачный фон с blur эффектом (backdrop-filter)
- Круглые иконки с отступами
- Анимация масштабирования при наведении
- Плавная прокрутка
- Адаптивная высота для мобильных устройств

#### Адаптивность:
- На мобильных: окна занимают весь экран, переключение через свайп
- На планшетах: 2 окна в ряд
- На десктопе: 4 окна в сетке 2x2

### Анимации:

1. **Открытие окна**: fade-in + scale
2. **Закрытие окна**: fade-out + scale
3. **Открепление**: transform + fade
4. **Прикрепление**: обратная анимация
5. **Переключение модулей**: slide + fade
6. **Hover на иконки dock**: scale(1.1) + shadow

### Интеграция с модулями:

- Каждый модуль должен предоставлять свой компонент для отображения в окне
- Модули регистрируются в системе через конфигурацию
- Роутинг работает внутри окон (каждое окно имеет свой router-view)
- Состояние модулей сохраняется при переключении

### Локальное хранилище:

- Сохранение позиций и размеров окон
- Сохранение открытых модулей в окнах
- Сохранение состояния dock (позиция прокрутки)

### Обработка событий:

- Keyboard shortcuts:
  - `Ctrl/Cmd + 1-4` - переключение между окнами
  - `Ctrl/Cmd + W` - закрыть активное окно
  - `Ctrl/Cmd + D` - открепить активное окно
  - `Esc` - закрыть модальные окна внутри окон

### Особенности реализации:

1. **Drag & Drop**:
   - Использовать библиотеку из модуля lsp   - Визуальная обратная связь при перетаскивании
   - Ограничения на перемещение (не выходить за границы контейнера)

2. **Resize**:
   - Resize handles по углам и краям окон
   - Минимальные и максимальные размеры
   - Сохранение пропорций при изменении размера

3. **Z-index управление**:
   - Активное окно всегда сверху
   - При клике на окно - оно становится активным

4. **Открепление окон**:
   - Вариант 1: Использовать window.open() для нового окна браузера
   - Вариант 2: Создать overlay с абсолютным позиционированием
   - Синхронизация состояния между основным окном и открепленным

5. **Модульная система**:
   - Динамическая загрузка компонентов модулей
   - Lazy loading для оптимизации
   - Кэширование загруженных модулей

### Тестирование:

- Тестирование на разных размерах экранов
- Тестирование drag & drop функциональности
- Тестирование открепления/прикрепления окон
- Тестирование переключения модулей
- Тестирование сохранения состояния

### Производительность:

- Виртуализация для большого количества модулей в dock
- Lazy loading компонентов модулей
- Debounce для resize событий
- Оптимизация анимаций (использование transform вместо изменения размеров)

### Доступность:

- ARIA атрибуты для всех интерактивных элементов
- Keyboard navigation
- Screen reader поддержка
- Контрастность цветов
