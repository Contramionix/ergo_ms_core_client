# Window Manager - Система управления окнами

## Описание

Система управления окнами для ERGO MS, позволяющая открывать до 4 модулей одновременно в отдельных окнах с возможностью перетаскивания, изменения размера и управления через нижнюю панель (dock).

## Использование

### Включение нового UI

Новый UI с окнами можно включить двумя способами:

1. **Через query параметр:**
   ```
   http://localhost:5173/?ui=windows
   ```

2. **Через localStorage:**
   ```javascript
   localStorage.setItem('ergo_ms_ui_mode', 'windows')
   ```

Для возврата к старому UI:
```
http://localhost:5173/?ui=menu
```
или
```javascript
localStorage.setItem('ergo_ms_ui_mode', 'menu')
```

### Открытие модулей

1. Кликните на иконку модуля в нижней панели (dock)
2. Модуль откроется в новом окне (если есть свободное место)
3. Если достигнут максимум окон (4), последнее окно будет заменено

### Управление окнами

- **Перетаскивание**: Зажмите заголовок окна и перетащите
- **Изменение размера**: Перетащите края или углы окна
- **Свернуть**: Кнопка "-" в заголовке
- **Развернуть**: Кнопка квадрата в заголовке
- **Закрыть**: Кнопка "X" в заголовке
- **Открепить**: Кнопка с иконкой внешней ссылки (пока не реализовано полностью)

### Структура компонентов

```
WindowManager/
├── WindowManager.vue          # Главный компонент управления окнами
├── Window.vue                 # Компонент отдельного окна
├── WindowHeader.vue          # Заголовок окна с кнопками управления
├── WindowContent.vue          # Контент окна (RouterView)
├── composables/
│   ├── useWindowDrag.js      # Логика перетаскивания
│   ├── useWindowResize.js    # Логика изменения размера
│   └── useWindowGrid.js      # Логика сетки окон
└── styles/
    ├── window.scss           # Стили окон
    └── animations.scss       # Анимации
```

## Store (Pinia)

Store находится в `@/stores/windowManager.js` и управляет:
- Состоянием всех окон
- Доступными модулями
- Активным окном
- Сохранением в localStorage

## Интеграция с модулями

Система автоматически загружает модули через `ModuleManager`:
- Использует `MenuManager` для получения конфигурации меню
- Использует `IconManager` для получения иконок
- Использует `RouteManager` для получения роутов

## Адаптивность

- **Мобильные (< 768px)**: Окна занимают весь экран
- **Планшеты (768px - 1200px)**: 2 окна в ряд
- **Десктоп (> 1200px)**: 4 окна в сетке 2x2

## Сохранение состояния

Позиции и размеры окон автоматически сохраняются в localStorage и восстанавливаются при следующем открытии.
